# Project Brief: Jelotia Imposer

## Vision & Scope
JELOTIA IMPOSER is a "Logiciel Professionnel d'Imposition Automatique Industrielle" developed for JELOTIA SARL, a company specializing in digital printing, advertising supports, stickers, large format printing, and personalized products.

The project aims to fully automate pre-press operations for thousands of print files daily, specifically:
- Verification (Preflight)
- Correction
- Classification
- Nesting (Imposition)
- Export to RIP

## Target Users
Internal operators at JELOTIA SARL handling high-volume daily print jobs.

## Business Goals
- Eliminate manual processing time and human errors.
- Reduce material waste via optimized nesting (fill rate target >= 75%).
- Scale production speed up to 10,000 files/day.
- Enable 24/7 automated operation via hot folders.
